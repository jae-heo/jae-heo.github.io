컴퓨터 구조에서 하드웨어의 실행 모델을 잡고, 리눅스에서 운영체제가 그 기계를 관리하는 방식을 봅니다. 컴파일러 시리즈는 소스 코드가 어떤 표현과 변환을 거쳐 실행되는지 연결해 줍니다.

언어와 런타임을 이해하고 싶다면

다음 두 시리즈부터 시작하세요.

  • 컴파일러
  • Python 심화 강좌

컴파일러 시리즈는 오토마타, 파싱, AST, IR, 최적화, 코드 생성을 다룹니다. Python 시리즈는 일상적인 코드에 더 가까운 곳에서 컨테이너, 제너레이터, 클래스, 디스크립터의 동작 원리를 설명합니다.

조금 가볍게 시작하고 싶다면

Python 심화 강좌부터 읽는 편이 좋습니다. 실무 프로그래밍 경험은 가정하지만 다른 시리즈만큼 낮은 수준의 배경지식을 요구하지는 않습니다.

그다음 리눅스 내부 구조로 넘어가면 언어의 동작을 프로세스, 메모리, 파일, 시스템 콜과 연결할 수 있습니다.
