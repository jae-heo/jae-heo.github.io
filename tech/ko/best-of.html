블로그 추천 글

지금 공개된 글 가운데 이 블로그의 색깔을 잘 보여 주는 시리즈와 글을 골랐습니다.

여기서 시작하기가 구조화된 경로라면, 이 페이지는 더 짧은 추천 목록입니다.

아래 링크는 모두 지금 읽을 수 있는 글로만 구성했습니다.

끝까지 읽어 볼 만한 시리즈

컴파일러

오토마타와 문법에서 출발해 파싱, AST, 의미 분석, IR, 최적화, 코드 생성까지 이어지는 이론과 구현의 경로입니다.

리눅스 내부 구조

프로세스, 스케줄링, 메모리, 파일, 시스템 콜, 동시성, 네트워크, 컨테이너를 잇는 시스템 경로입니다.

컴퓨터 구조

CPU 내부, 명령어 집합, 파이프라인, 권한 수준, 메모리 계층, I/O, 멀티코어 실행을 다루는 하드웨어 기초입니다.

Python 심화 강좌

가장 편하게 시작할 수 있는 시리즈입니다. 익숙한 Python 코드를 객체 모델, 컨테이너, 제너레이터, 클래스, 디스크립터의 동작 원리와 연결합니다.

먼저 읽을 만한 글 네 편

  • 중간 표현과 최적화는 컴파일러 이론을 실제 최적화기가 다루는 구조와 연결합니다.
  • 프로세스 스케줄링은 코드 실행을 운영체제의 정책과 연결하기 좋은 글입니다.
  • 메모리 계층 구조는 캐시, 지역성, 주기억장치를 이해하는 성능 모델을 잡아 줍니다.
  • 클래스의 내부 구조와 디스크립터는 자주 간접적으로 쓰지만 자세히 들여다보기 어려운 Python의 동작을 설명합니다.

하나의 흐름만 추천한다면

메모리 계층 구조, 프로세스 스케줄링, 중간 표현과 최적화 순서로 읽어 보세요.

하드웨어에서 런타임 정책을 거쳐 프로그램 표현으로 이동하는 흐름입니다.
